HOW TO EDIT
-----------
1. Open index.html with Notepad, Notepad++ or VS Code.
2. Search for "EASY EDIT AREA".
3. Change the text you want.
4. Save the file.
5. Double-click index.html to preview the website.

CHANGE THE DISCORD LINK
-----------------------
Search for:
https://discord.gg/CQDSGbFB6

Replace every occurrence with your new Discord invite.

CHANGE DEPARTMENT INFO
----------------------
Inside the "OUR DEPARTMENTS" section, you can change:
- Department name
- Recruitment status
- Description
- Apply / More Info button

IMPORTANT:
Keep the image files inside the assets folder.
If you rename an image, update its filename in index.html too.

CHANGE COLORS
-------------
At the top of index.html, edit the values under :root:
--red
--green
--gold
--gold2
--ink
--navy
--paper

DISCORD APPLICATIONS
--------------------
The website currently does not send application data directly to Discord.
This is intentional: putting a Discord webhook directly into public HTML
would expose it and allow other people to abuse it.

A secure Discord application system can be added later with a backend/serverless
function while keeping the website easy to edit.
